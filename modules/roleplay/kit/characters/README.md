# Character profiles

One Markdown file per character, named after the character (`Amiya.md`, `My-OC.md`).
The first line is `# Name (other names)`. The roleplay module gives API models (Anthropic or OpenAI-compatible) the profiles of the
player characters and of anyone mentioned, using these sections if present:

```markdown
# Name (Alias)

## Quick facts
## Looks
## Personality and voice
## Abilities
## Open questions
```

Write the profiles yourself, from sources you are allowed to use. Do not paste game
scripts or other copyrighted text into a public repository.
